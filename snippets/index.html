Why this page exists

YAML gives up on a whole file for one bad entry. A multi-line snippet is written as replace: | followed by indented lines — and the indentation is not cosmetic, it is what marks where the block ends. Paste text at the left margin and YAML decides the file ended there, so Espanso loads nothing: not just the broken snippet, but every other shortcut too. That has already happened once.

Copied text carries HTML escaping. Text out of a web page arrives with &#39; where an apostrophe should be, and it is easy not to notice until it types out literally.

So this page takes plain pasted text, indents it correctly, decodes the escaping, and shows you the exact file before it is written. Nothing here is clever — it removes two mistakes that cost far more than they should.
