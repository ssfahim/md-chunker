Why this page exists

YAML gives up on a whole file for one bad entry. A multi-line snippet is written as replace: | followed by indented lines, and that indentation is what marks where the block ends. Paste text at the left margin and YAML decides the file ended there, so Espanso loads nothing — not just the broken snippet, every other shortcut too.

Copied text carries HTML escaping. Text from a web page arrives with &#39; where an apostrophe should be, and it is easy not to notice until it types out literally.

This page indents pasted text correctly, decodes the escaping, and shows the exact file before it is written.
